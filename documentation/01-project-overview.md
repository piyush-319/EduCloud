# ☁️ EduCloud — Project Overview

> **Learn • Build • Deploy**

## 1. Introduction

EduCloud is an AWS-based cloud learning platform designed to help learners develop practical technical skills in AWS, Linux, DevOps, and Python.

It combines a React frontend with a Node.js and Express backend, deployed across separate AWS EC2 environments.

## 2. Problem Statement

Learners often understand technical concepts theoretically but lack opportunities to practice real-world cloud infrastructure, application deployment, and server management.

EduCloud aims to make technical learning more practical through structured learning paths, courses, lessons, and project-oriented content.

## 3. Project Objectives

- Build a cloud-hosted learning platform.
- Provide structured technical learning paths.
- Implement user registration and authentication.
- Display courses, lessons, and learning progress.
- Deploy frontend and backend on AWS.
- Establish private communication between application tiers.
- Understand application hosting and troubleshooting.

## 4. Key Features

- User registration and login.
- JWT-based authentication.
- User dashboard.
- AWS learning path.
- Linux & DevOps learning path.
- Python learning path.
- Course and lesson navigation.
- Learning progress display.
- Logout functionality.

## 5. Technology Stack

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | Node.js |
| API Framework | Express.js |
| Web Server | Nginx |
| Cloud | AWS EC2 |
| Networking | VPC Peering |
| Authentication | JWT |
| Containerization | Docker |

## 6. Application

**Website:** https://myeducloud.in

## 7. Learning Outcomes

This project provided practical exposure to AWS EC2, Linux server administration, React hosting, backend API deployment, Nginx reverse proxy, private network communication, JWT authentication, and troubleshooting.

## 8. Project Scope

EduCloud is a learning and portfolio project demonstrating practical cloud and DevOps concepts. It should not be represented as a certified production-grade platform.
